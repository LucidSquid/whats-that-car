# What's That Car?

This [live project](https://lucidsquid.github.io/whats-that-car/) utilizes a 201-layer Convolutional Neural Network (the DenseNet201 architecture) to predict the make and model of a vehicle from a user-inputted image.

- During testing, the model reached over **90% accuracy** on a dataset of 659 different vehicle models from 1950-2016.

- Images can be inputted via **dragging & dropping,** **pasting,** or **file browsing,** whatever is most convenient.

- Everything runs completely **on the client**, including the model, so no requests are sent to any server!
